# Weekend Projects

This repository contains side projects focused on data engineering, automation, and mathematical exploration.

## Projects

### 1. Math Scraper Project (Python + SQLite)
- **Location:** `/math-scraper-project/`
- **Description:** A Python script that scrapes mathematical data (prime numbers) from Wikipedia, parses the HTML using BeautifulSoup, and stores the data in a local SQLite database. It then runs SQL aggregate functions (COUNT, AVG, MAX) to analyze the stored data. 
- **Technologies Used:** Python, SQL (SQLite), BeautifulSoup, Git.
